🔧 Network Toolkit

5 essential network tools in ONE command-line application

✓ Windows ✓ Linux ✓ Open Source ✓ Free

🚀 Features

#ToolWhat it does
1📶 WiFi Password ManagerView & backup all saved WiFi passwords
2📊 Network Speed TesterTest download speed & ping latency
3📁 LAN File ShareShare files instantly on local network
4🌐 IP ScannerFind all devices connected to your WiFi
5📈 Network Usage MonitorSee which apps use bandwidth
6🚀 RUN ALLRun all 5 tools automatically!

🪟 Windows Installation

Step 1: Open PowerShell as Administrator (Windows + X → PowerShell Admin)

Step 2: Copy and paste this command:

irm https://raw.githubusercontent.com/FaizHacke/network-toolkit/main/toolkit.ps1 | iex

🐧 Linux Installation

Step 1: Open Terminal (Ctrl + Alt + T)

Step 2: Copy and paste this command:

curl -sSL https://raw.githubusercontent.com/FaizHacke/network-toolkit/main/toolkit.sh | bash

🎯 Quick Start

After running the toolkit, press 6 to automatically run all 5 tools!

💡 Pro Tip: Run as Administrator (Windows) or with sudo (Linux) for full features!

📊 Tool Details

1. 📶 WiFi Password Manager

Shows ALL WiFi networks your computer has connected to and their passwords. Option to backup to text file.

2. 📊 Network Speed Tester

Tests your actual download speed and ping latency. Rates your connection as Excellent/Good/Slow.

3. 📁 LAN File Share

Turns your computer into a file server. Share files with anyone on your WiFi network.

4. 🌐 IP Scanner

Scans your network and shows all connected devices with their IP addresses and hostnames.

5. 📈 Network Usage Monitor

Shows which applications are using your network bandwidth with visual connection bars.

6. 🚀 RUN ALL

Automatically runs Tools 1-5 and generates a complete report!

📄 Output Files

  • wifi_backup_YYYY-MM-DD_HH-MM.txt - Backup of all WiFi passwords
  • network_report_YYYY-MM-DD_HH-MM.txt - Complete diagnostic report

🛠️ Tech Stack

  • Windows: PowerShell, netsh, winget
  • Linux: Bash, nmcli, netstat, ping, curl
